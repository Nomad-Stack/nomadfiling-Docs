- Added real-time collaboration for documentation editing with multiple users.
- Introduced version history and rollback for pages.

- Improved mobile responsiveness for the editor interface.

## Bug Fixes

- Fixed issue where images failed to upload in certain browsers.

## Upgrade Instructions

Follow these steps to update your Nomadfiling instance to the latest version.

<Steps>
  <Step title="Backup Your Data" icon="database">

    Create a full backup of your documentation space.

    ```
    nomadfiling backup --output ./backup-$(date +%Y%m%d)
    ```

  </Step>
  <Step title="Update CLI" icon="download">
    <Tabs>
      <Tab title="npm" icon="package">
````bash
npm install -g nomadfiling@latest
````
      </Tab>
      <Tab title="yarn" icon="package">
````bash
yarn global add nomadfiling@latest
````
      </Tab>
    </Tabs>
  </Step>
  <Step title="Run Migration" icon="settings">

    Apply any database migrations.

    ```
    nomadfiling migrate
    ```

  </Step>
  <Step title="Restart Server" icon="refresh-cw">

    Restart your Nomadfiling server to apply changes.

    ```
    nomadfiling start
    ```

  </Step>
</Steps>
